# asthma-diagnosis
asthma-diagnosis Data Science project

## Go Kart Game

A simple go-kart game is provided in two formats in the `game` directory.

### Python version (Pygame)

Run this version locally with Pygame installed:

```bash
pip install pygame
python game/go_kart_game.py
```

Use the arrow keys to drive the kart around the track.

### HTML5 version

Open `game/go_kart_game.html` in a web browser to play directly without installing anything.
